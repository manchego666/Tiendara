# 🧾 Diagramas del sistema – Tiendara

En esta carpeta se encuentran los principales diagramas UML y gráficos de apoyo que representan la estructura y funcionamiento de la aplicación **Tiendara**.

---

## 🧍‍♂️ Caso de uso – Dueño

![CasoDeUso](https://github.com/manchego666/Tiendara/blob/master/Diagramas/CasosUso.png)

El actor principal **Dueño** puede realizar las siguientes acciones:

- Gestionar productos
- Registrar ventas
- Gestionar empleados
- Recibir proveedor
- Ver mapa y chatear con clientes
- Realizar corte de caja

---

## 🧱 Diagrama de clases

![DiagramaDeClases](https://github.com/manchego666/Tiendara/blob/master/Diagramas/DiagramaClases.png)
