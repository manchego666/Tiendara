# ROADMAP – Proyecto Tiendara

Este archivo describe las etapas de desarrollo previstas para **Tiendara**, el sistema de punto de venta gratuito con versión VIP para todo tipo de negocios.

Cada semana representa un avance estructurado, aunque puede ajustarse según disponibilidad y pruebas.

---

## ✅ Semana 1 – Estructura base y pruebas

- [x] Crear proyecto MAUI limpio (`Tiendara`)
- [x] Confirmar ejecución en emulador (Windows Machine)
- [x] Diseñar y aprobar logo oficial
- [x] Migrar clases del proyecto anterior (Producto, Venta, Empleado, etc.)
- [x] Configurar estructura de carpetas y documentación
- [x] Crear y subir `README.md`, `VISION.md`, `ROADMAP.md`

---

## 🔄 Semana 2 – Interfaz gráfica mínima

- [ ] Crear `MainPage.xaml` con botones principales (Inventario, Ventas, Configuración)
- [ ] Implementar navegación básica entre páginas
- [ ] Diseñar pantallas: Agregar Producto, Registrar Venta, Corte de Caja
- [ ] Añadir soporte visual para Android (iconos, diseño responsive)

---

## 🔄 Semana 3 – Lógica de datos y funciones base

- [ ] Programar lógica de inventario (alta, baja, modificación)
- [ ] Registrar ventas y generar corte de caja simple
- [ ] Agregar soporte para empleados: registro, modificación, pagos
- [ ] Configurar base de datos local (SQLite o SQL Server)

---

## 🔒 Semana 4 – Seguridad y usuarios

- [ ] Agregar sistema de inicio de sesión
- [ ] Clasificación de usuarios (Administrador, Empleado)
- [ ] Proteger accesos según tipo de usuario
- [ ] Guardado seguro de datos (opcional encriptación local)

---

## 💎 Semana 5 – Módulo VIP (funciones avanzadas)

- [ ] Escaneo de productos por cámara (código de barras)
- [ ] Mapa de tiendas con estado abierto/cerrado
- [ ] Chat entre usuario y tienda (con sistema antispam)
- [ ] Activación de versión VIP mediante token o pago manual

---

## 🧪 Semana 6 – Pruebas, feedback y ajustes

- [ ] Pruebas en múltiples celulares Android
- [ ] Revisión de rendimiento
- [ ] Ajustes visuales, texto, animaciones
- [ ] Optimización del diseño para velocidad y estabilidad

---

## 📦 Semana 7 – Distribución

- [ ] Generar APK estable
- [ ] Preparar entrada en Google Play (si aplica)
- [ ] Crear documentación final y materiales de promoción
- [ ] Publicar Tiendara beta
