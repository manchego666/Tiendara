# Tiendara

---

**Tiendara** es una aplicación moderna de punto de venta, desarrollada con **.NET MAUI** para dispositivos móviles y con posibilidad de adaptarse a PC. Su enfoque principal es brindar a los negocios pequeños y medianos de México una herramienta profesional, funcional y **gratuita** para gestionar su tienda.

Con Tiendara, cualquier negocio —desde una taquería, panadería, tienda de manga, hasta una santería o papelería— podrá registrar sus productos, ventas, empleados y proveedores sin pagar software caro ni depender de hardware especializado.

---

## 🚀 Características generales

- Aplicación de punto de venta **gratuita** con funciones completas.
- Desarrollo multiplataforma con .NET MAUI (Android, Windows).
- Uso local con opción a integración online en futuras versiones.
- Interfaz sencilla, bonita y adaptable a cualquier giro comercial.
- Código fuente **privado**. Todos los derechos reservados © 2025 ZorroDev.

---

## 🧰 Funciones principales (versión gratuita)

- Gestión completa de productos: agregar, modificar, eliminar.
- Control de inventario y recepción de proveedores.
- Registro de ventas, con corte de caja diario.
- Gestión de empleados (registro, pagos, roles).
- Reportes básicos de venta.
- Alerta de stock bajo.
- Base de datos con SQL Server integrada.
- Compatible con celulares de gama media en adelante.

---

## 💎 Funciones VIP (versión de pago)

- Escaneo de productos con cámara (código de barras).
- Mapa interactivo con tiendas registradas (abierto/cerrado).
- Chat cliente-tienda con sistema antispam.
- Reportes estadísticos avanzados.
- Panel de administración premium con interfaz personalizada.
- Soporte técnico y tutoriales interactivos.
- Verificación de empleados con huella digital (compatible con lector).
- Acceso desde múltiples dispositivos sincronizados.
- Prueba gratuita de 5 días con todas las funciones.

---

## 💼 Modelo de negocio

- **Gratis:** para negocios que solo requieren lo esencial.
- **VIP:** 40 a 100 MXN/mes según uso de base de datos y recursos.
- Precios accesibles para mantener el sistema y expandir soporte.

---

## 🌍 Misión del proyecto

> Llevar un sistema de punto de venta moderno, económico y seguro a todo México (y el mundo), permitiendo a cualquier negocio —por más pequeño que sea— competir con herramientas digitales sin necesidad de gastar miles de pesos en software y hardware.

Queremos que Tiendara sea la **nueva forma de ir a la tienda**:  
Consultar el mapa, ver si está abierta, preguntar por un producto, y acercarte sabiendo que te están esperando.
